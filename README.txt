ПРЕПОДАВАТЕЛЬ КАФЕДРЫ СВЯЗИ ЩЕРБА АНТОН ИВАНОВИЧ
=====================================
(файловый менеджер для организации учебных материалов)

Что это
-------
Простая программа для организации учебных материалов по схеме:

    Дисциплина -> Тема/Занятие -> Файлы (лекции, презентации, задания и т.д.)

При добавлении файла в занятие программа копирует его в свою папку
"Материалы" рядом с программой (у каждой пары дисциплина/занятие — своя
подпапка). Оригинал при этом остаётся на месте, программа работает со
своей копией — поэтому даже если исходный файл потом переместят,
переименуют или удалят, в программе он никуда не денется. Все файлы можно
открыть прямо из программы двойным кликом (откроются в стандартной
программе Windows: Word, PDF, проигрыватель и т.п.).

Из-за копирования программа занимает на диске примерно столько же места,
сколько сами учебные материалы (плюс немного на структуру папок) — это
осознанный компромисс в пользу надёжности ссылок. Если материалы большие
(много видео), стоит иметь это в виду при выборе диска для установки.

Название дисциплины должно быть уникальным (как и название занятия внутри
одной дисциплины) — программа не даст создать или переименовать в
название, которое уже занято. Это сделано специально: папки в "Материалы"
называются просто по имени дисциплины/занятия, без служебных добавок, и
уникальность названий — единственное, что не даёт им перепутаться.

Структура сохраняется в файл data.json рядом с программой, поэтому при
следующем запуске всё восстановится автоматически. Перед каждым сохранением
автоматически создаётся резервная копия data.json.bak.

Совместимость с Windows 7
--------------------------
Программа написана на чистом Python (модуль tkinter, входит в стандартную
поставку) — никаких сторонних библиотек не требуется.

Чтобы запустить на Windows 7:

1. Установить Python. Т.к. Windows 7 не поддерживается свежими версиями
   Python (начиная с 3.9 официальная поддержка Win7 прекращена), нужно
   поставить Python 3.8.10 — последнюю версию с официальной поддержкой
   Windows 7:
   https://www.python.org/downloads/release/python-3810/
   (файл "Windows x86-64 executable installer" или "Windows x86 executable
   installer" для 32-битной системы)

2. При установке отметить галочку "Add Python to PATH".

3. Скопировать на компьютер преподавателя файл teacher_file_manager.pyw
   вместе с папкой assets (в ней иконка и эмблема — без неё программа
   запустится, но без значка и картинки в шапке) и файлом
   "Инструкция для капитана Щербы.txt" (без него кнопка "Справка" в
   программе покажет ошибку, что файл не найден).

4. Просто дважды кликнуть по файлу — программа запустится без открытия
   чёрного окна консоли (расширение .pyw запускает без консоли).

Вариант без установки Python (отдельный .exe)
-----------------------------------------------
Если преподавателю не нужно/нельзя ставить Python, можно собрать
отдельный .exe-файл при помощи PyInstaller. Это нужно сделать один раз,
на компьютере с Windows 7 и Python 3.8.10 (собранный на Win7 exe запускается
и на Windows 10/11 без переустановки — это и есть рекомендуемый способ
переносить программу между разными компьютерами кафедры):

    pip install pyinstaller
    pyinstaller --onefile --noconsole --name "Файловый менеджер" teacher_file_manager.pyw

Готовый .exe появится в папке dist\. Его можно скопировать на флешку и
запускать на любом компьютере с Windows 7/10/11 без установки Python —
данные (data.json) при первом запуске создадутся рядом с самим exe.

Важно: папку assets (в ней иконка программы и эмблема ВУЦ) нужно скопировать
вместе с exe в ту же папку — они не встраиваются внутрь exe, без них
пропадут значок программы и эмблема в шапке окна.

Как пользоваться
-----------------
1. Левая колонка "Дисциплина" — кнопка "Добавить" создаёт новую дисциплину
   (например, "Электротехника", "Программирование микроконтроллеров").
   Строка поиска над списком фильтрует по названию. Список дисциплин всегда
   отсортирован по алфавиту — свой порядок здесь не настраивается.
2. Средняя колонка "Тема/Занятие" — после выбора дисциплины добавляются
   темы/занятия (например, "Занятие 1. Введение", "Лабораторная работа №2").
   Тут тоже есть поиск, перестановка порядка кнопками ▲/▼ и переключатель
   "А-Я" / "Свой" порядок отображения.
3. Правая колонка "Файлы занятия" — после выбора занятия кнопкой
   "Добавить файл..." прикрепляются нужные файлы с компьютера
   (презентации, документы, видео, архивы — любые). Программа копирует
   выбранные файлы в свою папку "Материалы" — исходные файлы при этом не
   трогаются. Можно выделить сразу несколько файлов (Ctrl/Shift+клик) и
   убрать их разом. Если своя копия файла всё же пропала (например, кто-то
   вручную удалил её из папки "Материалы"), в списке она помечается
   красным как "[не найден]" — чтобы восстановить, достаточно нажать
   "Добавить файл..." и выбрать тот же файл ещё раз: копия встанет точно
   на прежнее место, программа не заведёт для неё вторую, дублирующую
   ссылку (проверяет по итоговому пути на диске).
   Всё, что закинуто вручную через проводник прямо в "Материалы" (в обход
   кнопок программы) — новый файл в папке занятия, новая папка занятия
   внутри дисциплины или целиком новая папка дисциплины — программа
   подхватывает сама при следующем запуске, без отдельной кнопки.
   Кнопка "Убрать" не удаляет собственную копию файла безвозвратно, а
   переносит её в папку "Корзина" рядом с программой (с той же структурой
   Дисциплина/Занятие) — на случай, если файл понадобится снова. Внешние
   ссылки (не скопированные в "Материалы" файлы из старых записей) при
   этом не трогаются, программа ими не владеет.
4. Двойной клик по файлу или кнопка "Открыть" — открывает его в
   стандартной программе.
5. Кнопка "Показать в папке" — открывает проводник с выделенным файлом.
6. Переименование и удаление дисциплин/тем — соответствующими кнопками,
   либо двойным кликом по дисциплине/занятию (сразу открывает переименование).
   При переименовании соответствующая папка в "Материалы" переименовывается
   вслед за названием — структура на диске всегда соответствует программе.
   Удаление занятия/дисциплины убирает их из программы, а все прикреплённые
   собственные копии файлов переносит из "Материалы" в "Корзина" (внешние
   ссылки на файлы вне "Материалы" не трогает).
   Если внутри дисциплины или занятия есть хотя бы один пропавший файл —
   рядом с названием появляется значок ⚠, чтобы не пришлось открывать
   каждую по очереди в поисках проблемы.
7. Кнопки "A-" / "A+" в правом верхнем углу увеличивают и уменьшают размер
   шрифта во всём интерфейсе; выбранный размер запоминается между запусками.
8. Правый клик по любому из трёх списков открывает контекстное меню — набор
   действий зависит от того, куда кликнули: по пункту (переименовать,
   удалить, переместить и т.д.) или в пустую область списка (только
   "Добавить").
9. Панель под шапкой окна — общие инструменты по всей базе:
   - "Справка" — открывает файл "Инструкция для капитана Щербы.txt"
     (короткое неформальное руководство, лежит рядом с программой).
   - "Проверить файлы" — пробегает по всем дисциплинам и занятиям и
     показывает список файлов, которые пропали с диска (например, после
     переноса на другой компьютер или флешку).
   - "Экспорт плана..." — сохраняет список дисциплин/занятий/файлов
     (без полных путей, только имена файлов) в обычный текстовый файл —
     удобно для печати или отчёта.
10. При самом первом запуске (пока ещё нет data.json) программа один раз
    показывает приветственное окно с кратким объяснением структуры —
    дальше, пока данные не удалены, больше не появляется.

Чтобы перенести всю базу на другой компьютер или флешку, копируйте вместе:
файл программы, data.json и папку "Материалы" целиком (в ней лежат
собственные копии всех прикреплённых файлов) — тогда всё заработает сразу,
без единой сломанной ссылки. Папку "Корзина" переносить не обязательно —
на работу программы она не влияет, это просто архив убранных файлов. Для старых записей, сделанных ещё в режиме
ссылок, по-прежнему важно, чтобы совпадали пути к исходным файлам — если
файл всё же не нашёлся ("Проверить файлы" покажет список), достаточно
прикрепить его заново кнопкой "Добавить файл...".
